## Custom Project

### Dataset

The dataset used was sales.csv, which contains sales transaction records for
online learning products. Fields include order ID, date/time, region, currency,
product ID, unit price, quantity, customer information, device type, payment
method, referral source, discount code, and customer notes. I used the example
dataset without modifications.

### Kafka Messages

The producer sent sales transaction records as JSON messages through the Kafka
topic configured in the project. Each message represented one sale and contained
the fields from the dataset. I did not modify the message structure.

### Consumer Processing

The consumer received sales messages from Kafka, validated required fields,
calculated derived values such as subtotal, tax amount, and total sale amount,
and updated running statistics. Processed records were written to a CSV file and
displayed in a live chart.

### Experiments

For Phase 4, I modified the visualization by adding a running average line and
displaying the average sale amount in the chart title.

For Phase 5, I extended the visualization to compare individual sales totals
against the running average, making it easier to identify larger and smaller
transactions.

### Results

The consumer successfully processed all sales messages, updated the live chart,
and saved the output data. The chart displayed individual sales totals along
with a running average line.

### Interpretation

The running average provided additional insight into sales performance
throughout the stream. Most transactions remained near the average, while a few
larger purchases stood out as outliers. This demonstrated how Kafka can be used
to process, analyze, and visualize business data in real time.
